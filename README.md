# Manual Testing Portfolio — SauceDemo

This repository is a manual testing portfolio for [SauceDemo](https://www.saucedemo.com)
(Swag Labs), a public e-commerce practice site built for testing practice. It shows how I
approach testing as a QA fresher: a written test plan, 34 hand-designed test cases covering
positive, negative, boundary, UI and exploratory scenarios, a defect template and bug log,
and a small Python (standard library only) reporting pipeline that turns my CSV results into
a summary report. No automation or load tests are run against the site — every result in this
repo is meant to come from a real manual test run.

**Author:** Aniruddha Yadav · QA fresher

## What I tested

| Module | Focus |
|--------|-------|
| Login | Valid/invalid credentials, empty fields, locked-out user, SQL-injection-style input, whitespace & case sensitivity, error wording, password masking |
| Inventory | Item count, product images, name/price consistency, add/remove from list, cart badge |
| Sorting | Name (A–Z, Z–A) and price (low→high, high→low) |
| Product Details | Navigation, back button, add to cart from the detail page |
| Cart | Multiple items, remove, continue shopping, persistence after refresh |
| Checkout | Field validation, special characters, total/tax calculation, cancel, finish, confirmation |
| Menu / Logout | Logout, browser back button after logout, About and Reset App State links |
| Cross-user behaviour | Exploratory comparison of `problem_user` and `visual_user` against `standard_user` |
| Responsive / UI | One basic responsive layout check |

## How to read the results

- `test-cases/test_cases.csv` holds the expected results; `Actual_Result`, `Status`,
  `Evidence` and `Notes` stay **empty until a test is actually executed** — I never fill
  them in advance.
- `Status` is one of **Pass / Fail / Blocked / Not Run**. An empty status counts as *Not Run*.
- The **pass rate** is calculated only from *executed* cases (Pass + Fail + Blocked), so a
  fresh sheet never shows a misleading percentage.
- Failed cases point to a bug in `bug-reports/bugs.csv`; screenshots live in `evidence/`.
- The tables below are regenerated by `python scripts/generate_summary.py`.
